# AssetsLoaderMod

Mod de Minecraft Java Edition para mostrar un indicador de carga de recursos con estética vanilla durante la carga de mundos y servidores.

## Diseño

- Indicador en la esquina inferior izquierda.
- Recuadro blanco con baja opacidad.
- Tipografía y estética inspiradas en la interfaz vanilla de Minecraft.
- Primera línea: `Cargando Assets`.
- Segunda línea: `0/1 Assets cargados`, actualizada dinámicamente.
- Barra de progreso debajo del texto.
- Sin bordes redondeados, iconos, sombras decorativas ni colores llamativos.
- No modifica la pantalla inicial al abrir Minecraft.
- Objetivo de compatibilidad: Minecraft 1.20–1.20.6, con 1.20.1 como versión principal de desarrollo.
- Debe cubrir carga de mundos singleplayer y entrada a servidores.
